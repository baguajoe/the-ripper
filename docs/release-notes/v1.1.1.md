## The Ripper 1.1.1

Fixes everything found when testing 1.1.0 on a real Windows 11 PC, and adds video drop-in.

### Fixed
- **Crash while analyzing a song (engine exited with 0xC0000005).** Key detection no longer runs the heavy full-rate analysis that crashed; it now works on downsampled mono audio, so a 4-minute song analyzes in seconds, not ~30 s. Numeric libraries are capped at 8 threads on many-core PCs, and numba compiles into a writable per-user cache.
- **One bad file can't take the app down.** Analysis, stem separation and export run in separate worker processes. If one crashes, only that job fails, with a clear message and a **Retry** button. The engine keeps running, and a stack trace is written to `engine-crash.log` in the log folder (it's included in Help → Copy Diagnostics).
- **The engine restarts itself.** If the engine stops, the app restarts it (up to 3 times a minute). The status dot turns red while it's down, and the library reloads when it's back. Tracks never sit on "Analyzing" forever.
- **"Could not load library: Failed to fetch".** The UI now waits for the engine and retries with backoff. It only reports an error when the engine is really down.
- **Drag and drop into the app.** Drop files anywhere in the window. The drop area highlights while you drag, and unsupported files get a clear message. On Windows, if the app was started as administrator (e.g. from an elevated installer), it relaunches itself as the normal user, because Windows blocks drag-and-drop from Explorer into elevated apps.

### New
- **Video drop-in:** MP4, MOV, M4V, WEBM and MKV (up to 500 MB). The audio is extracted (44.1 kHz stereo WAV) and the video isn't kept. Videos without an audio track are rejected with a message. Audio files keep the 200 MB limit.
